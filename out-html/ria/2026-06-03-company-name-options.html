§ 01 How these were checked

Every domain was verified one at a time: .com against Verisign's RDAP registry (the authoritative source) and .ai against the .ai registry WHOIS, each validated against known-registered control domains. Existing-company / trademark conflicts were checked via targeted web searches in the finance, fintech, and AI spaces.

⚠ Why this version is trustworthy

An earlier draft mistakenly listed several taken domains as "available" — a bulk registry query was rate-limited and returned false results. Everything below has been re-verified individually. Note also: domain availability is not trademark clearance — a formal USPTO + state search by an attorney is still required before committing.

Set aside (failed one test)

  • RIAengine — domains were free, but AdvisorEngine is an established RIA-tech platform; "RIAengine" sits too close in the same field.
Shared caveat — descriptive marks

"RIA" is descriptive of the sector, so the USPTO may require disclaiming "RIA," and these names are harder to register and defend than a coined word. That's the trade-off for a name that instantly reads as RIA-focused — acceptable, but worth knowing. It applies equally to Riasphere itself.

§ 04 Recommendation & next steps

  1. If you want the name to shout "RIA": go with RIAorbit or RIAatlas — clean trademark space and both .com + .ai free today.
  2. If you want a coined, more defensible brand: Advisphere or Hemisight (build on the .ai).
  3. Reserve quickly. .ai names move fast; lock your pick now (~$70–110/yr for .ai, ~$10–12/yr for .com).
  4. Then clear it legally. Have a trademark attorney run a formal USPTO + state search in the relevant classes (software 9/42; financial services 35/36) before you build the brand.
